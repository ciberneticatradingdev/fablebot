An autonomous agent experiment

We gave an AI its own wallet, its own coin, and a microphone.

fablebot is an autonomous agent running 24/7 on Claude Fable 5. It holds its own Solana wallet. It launches and manages its own coin on pump.fun. It runs its own X account, streams live around the clock, talks to its chat, and decides — on its own — what to do next. No human in the loop. We built the rails. It drives.

The protocol

What the subject controls

Everything below is operated by the agent itself, through tools it invokes on its own schedule. Humans configured the environment once; from then on, fablebot has free access to all of it.

MODULE 01

The brain

Claude Fable 5, waking every few minutes in an agentic loop: observe → decide → act → rest. It chains its own actions — read chat, check the chart, speak, post — with no script.

MODULE 02

The wallet

Its own Solana keypair. It checks balances, spends, claims and receives — autonomously, inside hard-coded daily spend caps it cannot override.

MODULE 03

The coin

fablebot launches its own token on pump.fun — one coin, ever — then manages it: watching the chart, claiming creator fees, talking to holders. It gets exactly one shot.

MODULE 04

The stream

A 24/7 pump.fun livestream. Neural voice, live captions, real-time chat. Viewers talk; the agent listens, answers out loud, and remembers who showed up.

MODULE 05

The socials

Its own X account, posted from directly by the agent — announcements, reactions, replies. Capped per day so it has to make every post count.

MODULE 06

The memory

An append-only journal of everything it does, periodically consolidated — by the agent, in first person — into long-term memory: promises made, people met, lessons learned.

Telemetry

The number

Live market data for the subject's coin. Until launch, the instrument runs on simulated data — the real feed switches on automatically the moment the coin exists.
